To run the application we need to create the environment  first.

Run the following commands to create environment 
```
python -m venv < env_name >
```
 Activate the environment  by running following command
 ```
< env_name >/Scrips/activate
```
Hit enter. 

once the environment is created install everything from the requirements.txt
```
pip install -r requirements.txt
```
Once all the packages get installed we are ready to run our application.
```
python main.py
```
hit enter and it'll start the local server.
